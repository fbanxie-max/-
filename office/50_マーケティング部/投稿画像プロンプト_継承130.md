# 投稿画像プロンプト（ChatGPT用）｜テスト投稿①「継承10ヶ月で130%」

> ChatGPT(チャッピー)の画像生成に貼るプロンプト。狙い＝"AI感(のっぺりフラット)"を消し、雑誌特集ページのような人の手感・質感を出す。
> ※数字・日本語は生成AIが崩しやすい。出たら必ず数字を目視チェック。崩れたら「この数字を正確に」と指示 or 背景だけ作らせてCanvaで文字を乗せる。

## プロンプト（コピペ用）
```
あなたは一流のグラフィックデザイナーです。
Threads/Instagram用の縦型(4:5)投稿画像を1枚デザインしてください。
テーマ：現役の美容室オーナーが、事業を継承して約10ヶ月で売上130%にした実績。

【最重要】いわゆる"AIっぽい"のっぺりしたフラットデザインは絶対に避けること。
雑誌の特集ページのような、余白・質感・空気感のある、人の手で組んだ上質な編集デザインに。
安っぽいグラデーション、ステレオタイプなテック感、左右対称すぎる構図はNG。

■ アートディレクション（雰囲気）
- 美容・ライフスタイル誌の特集ページ風。上品で温かみがある大人のトーン。
- 紙や布のかすかな質感、繊細でリアルな影、わずかなグレイン(粒状感)。
- ミニマルだが余白に意味がある構図。手描き風のあしらいを少しだけ。
- 「高級感 × 親しみやすさ」の両立。

■ 配色
- ベース：温かいオフホワイト/生成り。
- 主役の差し色：くすみローズ（またはテラコッタ）を1色だけ主役に。
- アクセント：深いグリーンをほんの少し。
- 彩度は上げすぎず、大人っぽく。

■ タイポグラフィ（日本語は誤字ゼロ・正確に）
- 見出し：太めの日本語ゴシック。数字：存在感のあるコンデンス体かセリフ体。
- 文字は大きく、可読性を最優先。

■ レイアウトと入れる文言（この通り正確に）
- 上部の小さめラベル：「現役 美容室オーナー ／ 事業継承の記録」
- メイン見出し：『美容室を継いで10ヶ月。売上130%』（"130%"を特大で主役に）
- サブ：『"何でも屋"をやめて、専門店に振り切った。』
- 数字ブロック（すっきり整理）：
   ・客単価 7,200円(2024) → 8,000円(2025) → 8,500円(2026)　※右肩上がりが伝わる簡単な線を添えて
   ・新規客 月57名（ホットペッパーのみ）
   ・勝因：「専門特化」（＝一番効いた打ち手。※130%はメイン見出しにあるので繰り返さない）
- 下部に控えめに：「@salon_ai_ceo ／ 続きはプロフィールのnoteへ」

■ 仕様
- 縦4:5。余白しっかり。ロゴや透かしは入れない。
- 日本語テキストは崩さず正確に。読みやすさ最優先。

まずこの内容で1枚作ってください。
```

## 使い方・微調整のコツ
- **数字は必ず目視チェック**。1桁でも違ったら「客単価は 7,200→8,000→8,500円、新規は月57名、売上130%。この数字を正確に直して」と返す。
- 文字がどうしても崩れる時：**「文字なしで背景/世界観だけ作って」**→ Canvaで文字を自分で乗せると確実。
- 雰囲気を寄せたい時：**好きなデザインの参考画像を1枚添付**して「このトーンで」と言うと一発。
- スタイルの言葉（雑誌風／くすみローズ 等）は好みで差し替えOK。もっとポップにしたいなら「明るくポップに、色数多めで」に変える。
