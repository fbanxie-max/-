# 写真加工プロンプト集（ChatGPT / 画像AI用）

> 目的：実際のサロン写真を「上質な美容室のSNS投稿」に見えるよう加工する、コピペ用プロンプト。
> ⚠️ AIは画像内の日本語文字が崩れやすい。**写真の加工＝AI／文字のせ＝Canva等**が確実。プロンプトは「文字を置く余白」を作らせる方針。
> ⚠️ 誇張はしない（実際の仕上がりを盛りすぎると信頼を失う）。お客様が写る場合は必ず本人の掲載許可を取る。

## 世界観（最初に一度だけ決める・下は推奨デフォルト）
- **トーン**：清潔感・透明感・上品・ナチュラル（髪質改善サロンらしい"信頼と上質"）
- **カラー**：ベース＝白／グレージュ／ベージュ、アクセント＝くすみゴールド `#C9A96A`（または上品なボルドー `#7B2D3B`）
- **フォント（Canvaで文字のせ時）**
  - 見出し（和）：Shippori Mincho / Noto Serif JP（細めの明朝）
  - 見出し（英）：Cormorant Garamond / Playfair Display（上品なセリフ）
  - サブ・価格：Noto Sans JP Light（細ゴシック）
- **余白**：多め・1枚1メッセージ・色は2つ/フォントは2種まで

## 【共通プロンプト】写真のレタッチ（コピペ）
```
この美容室の写真を、上質なサロンのSNS投稿用に自然にレタッチしてください。
・髪のツヤと毛流れを美しく、ただし自然に強調（やりすぎない）
・肌はヘルシーでナチュラルに（盛りすぎない）
・ホワイトバランスを整え、全体を少し明るく、彩度は上品に抑える
・背景は明るく清潔に、余計な写り込みや雑多なものを整理
・白〜ベージュ基調の、透明感のある上品な仕上がり
・加工しすぎず、実際の仕上がりを誇張しない（信頼が第一）
・上部または下部に、あとで文字を置けるすっきりした余白を残す
・構図は縦4:5（Instagram）／9:16（ストーリー）で整える
出力は加工後の写真のみ。写真内に文字は入れないでください。
```

## 用途別の足し込みプロンプト（共通プロンプトの後ろに続ける）

### A. ビフォーアフター（髪質改善・縮毛矯正）
```
左＝ビフォー、右＝アフターの2分割レイアウト。
両方を同じ明るさ・色温度に統一。アフター側の髪のまとまり・ツヤを自然に強調（誇張しない）。
中央に細い区切り線。下部に「Before / After」の文字を後のせできる余白を確保。
```

### B. スタイル写真（HPB・Google用）
```
被写体を中央〜やや上に配置し、背景は無地に近い明るいトーンに整理。
顔まわり・毛先のディテールがはっきり見えるように。
下1/4に、メニュー名を後のせできる余白（明るい単色帯 or 軽いぼかし）を作る。
```

### C. クーポン／メニュー訴求バナー
```
写真を背景に、右または下に「文字ゾーン用の余白」を大きめに確保。
文字ゾーンは白の半透明、またはブランド色（くすみゴールド）の帯で写真と分離。
余白の効いた、高級感のあるミニマルな構図に。
```

### D. Instagramフィード統一（毎回つける）
```
毎回同じ設定で：明るさ・彩度・色温度・余白の位置をそろえる。
フィードに並べたとき世界観が統一されて見えるトーンで。
```

## Canvaで文字をのせる時の指定
- **見出し**：Shippori Mincho / Noto Serif JP（細身の明朝）、字間広め、言葉は少なく
- **英字の飾り**：Cormorant Garamond など上品なセリフ
- **サブ・価格**：Noto Sans JP Light
- **文字色**：ダークグレー `#333333` かブランド色。白背景 or 半透明帯の上にのせる
- **鉄則**：1枚に色は2つまで／フォントは2種まで／余白たっぷり／情報は1つに絞る
