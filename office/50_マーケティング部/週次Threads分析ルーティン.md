# 週次 Threads分析ルーティン（検索 → 分析 → 改善のPDCA）

> 2026-07-28 新設 / 2026-07-28 **API自動取得を追加**。実行は毎週月曜、`/threads-weekly` コマンド。
> ⚠️ Claude Codeの実行環境からは `graph.threads.net` が遮断されているため直接APIを叩けない。
> → **GitHub Actions（GitHub側のサーバー）が毎週月曜10:00 JSTにThreads APIでデータ取得し、リポジトリに保存**する仕組みを構築（`automation/README_Threads週次自動取得.md`）。

## 役割分担
| 誰 | やること | 時間 |
|---|---|---|
| **GitHub Actions（自動）** | 自分の投稿インサイト＋キーワード検索（伸びてる投稿）をAPIで取得・保存 | 0分 |
| **オーナー** | APIで取れない指標だけスクショ（**保存数・プロフィール流入**） | 2〜3分 |
| **AI CEO** | 自動取得データ＋スクショを分析→勝ちパターン更新→**今週の投稿案**まで | 全部 |

## 自動取得されるファイル（AIはまずこれを読む）
- `office/30_分析部/YYYY-MM-DD_Threads自動取得.md` … 人が読むダイジェスト
- `office/30_分析部/YYYY-MM-DD_Threads自動取得.json` … 分析用の生データ（キーワード検索結果を含む）
- `office/30_分析部/Threads投稿インサイト.csv` … 毎週追記される履歴

## オーナーが手で補うもの（APIに無い指標）
1. **保存数・プロフィール流入**：Threadsアプリのインサイト画面をスクショ（2〜3分）。
2. （キーワード検索が権限で取れていない週のみ）**伸びてる投稿を3〜5本スクショ**。
   - 探し方：検索窓で「美容室 経営」「サロン 集客」「個人事業 AI」「客単価」など。おすすめ面で伸びてるものでも可。
   - 見るポイントはAIがやるので、**深く考えず数を撮るだけでOK**。

## AI CEOがやること（毎週の手順）
0. **まず自動取得ファイルを読む**：`30_分析部/` の最新 `*_Threads自動取得.md` / `.json`（無ければ「Actionsが動いていない/トークン切れ」を疑い、オーナーに伝える）。
1. `30_分析部/KPI記録.csv`・`勝ちパターンメモ.md`・`失敗リスト.md`・`50_マーケティング部/発信シリーズ設計.md` を読む。
2. **自分の数字を記帳**（KPI記録.csvに追記）。先週比・伸びた/落ちた投稿を特定。
3. **バズ投稿の分解**：もらったスクショを、以下の観点で構造分析する。
   - フックの型（数字/断言/失敗告白/問いかけ/逆張り/リスト）
   - 1行目の文字数・語り口・改行の使い方
   - 「誰の何の悩み」に当てているか
   - CTA（問いかけ・誘導）の有無と形
   - 画像の有無・種類（テキスト画像/実写/グラフ）
   - 投稿時間帯（分かれば）
4. **自分の投稿と比較**→ 差分を言語化（何が足りないか）。
5. **勝ちパターン更新**：`30_分析部/勝ちパターンメモ.md` に、確認できた法則を追記（推測は"仮説"と明記）。
6. **今週の改善アクション**を3つに絞って提示（例：フックを数字型に／1行目を15字以内に／画像をグラフ型に）。
7. **今週の投稿案を2〜3本**、コピペ完成形（コードブロック）で納品。必要なら画像プロンプトも添付。
8. `週次レポート`を `30_分析部/YYYY-MM-DD_週次Threads分析.md` に保存し、コミット＆プッシュ。

## 判定基準（KPIの優先順位）
1. **保存数** 2. **プロフィール流入** 3. **note誘導クリック** 4. 返信数 5. 表示数 6. いいね
※いいねが少なくても、保存・プロフィール流入が出ていれば刺さっている。フォロー転換は「返信・会話」で起きる（既存調査）。

## 材料が集まらなかった週の動き
オーナーからスクショが無い場合でも止めない：
- 自分のKPI推移だけで分析→改善案を出す。
- 一般的なトレンドが必要なら、**ディープリサーチ依頼文**（`90_テンプレート/ディープリサーチ依頼テンプレ.md`のローテ⑤=Threadsアルゴリズム/トレンド）を出して、オーナーにChatGPT/Claudeで実行してもらう。

## 変更したいとき
- 曜日・時間の変更／停止は、オーナーがCEOに「週次分析、◯曜◯時に変更して」と言えばOK（Routineを更新する）。
