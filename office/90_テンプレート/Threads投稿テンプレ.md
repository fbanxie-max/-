# Threads投稿の型(テンプレート)

マーケティング部はこの型を使い分けて投稿を作る。全投稿共通: 1行目で止める・500文字以内・1投稿1メッセージ。

## 型A: 共感あるある型(ファン化用・使用頻度高)
```
(ターゲットの「わかる!」という日常の1シーン)
(あるあるの深掘り2〜3行)
(共感の締め or 軽い問いかけ)
```

## 型B: 価値提供型(保存される投稿)
```
(結論: ○○は△△が9割、みたいな言い切りフック)
(理由・具体的な方法を箇条書き3〜5個)
(まとめ1行+「保存して見返してね」等の行動喚起)
```

## 型C: ストーリー型(信頼構築)
```
(過去のダメだった自分の1シーン)
(転機・気づき)
(今の変化)
(読者への一言)
```

## 型D: 導線型(note誘導・全体の2割まで)
```
(noteに書いた内容の一番おいしい部分をチラ見せ)
(得られる変化を1〜2行)
(「続きはnoteに書きました→プロフィールから」)
```

## 型E: 問いかけ型(リプライ促進)
```
(ターゲットが答えたくなる二択 or 質問)
(自分の答えを先に軽く開示)
```
