# ディープリサーチ依頼テンプレ（毎月・⑥SEO・リサーチ室）

> 使い方：毎月、下の「基本ブロック」＋その月の「テーマ別ブロック」を貼り合わせて、
> **ChatGPT または Claude の「ディープリサーチ / Research」機能**に貼って実行 → 結果をCEO(Claude Code)に共有 → CEOが打ち手化して `20_リサーチ部/YYYY-MM_テーマ.md` に保存。
> 毎月の構成：**固定2本（①競合サロン定点／②翌月の季節需要）＋ 月替りローテ1本（③→④→⑤→⑥→③…）**。

---

## ■ 基本ブロック（毎回いちばん上に付ける）

```
あなたは日本の美容室オーナーの経営参謀です。以下の店の視点で、最新情報をディープリサーチしてください。

【店の前提】
- 大阪市住吉区あびこ（あびこ駅前）の個人経営の美容室。スタッフ数名。
- 強み・主力メニュー：髪質改善／縮毛矯正／酸性ストレート／ヘッドスパ／白髪ぼかし・白髪染め／ショート。
- 集客：ホットペッパービューティー(HPB)掲載あり、Googleビジネスプロフィール運用中。
- 一般カラー（ハイライト・ダブルカラー等）はSEO/集客の主対象にしていない。

【リサーチの条件】
- 対象期間：2025年後半〜2026年の最新情報を優先（古い情報は明示）。
- 日本国内・できれば関西/大阪の事情を優先。
- 一次情報・公式発表・信頼できる業界メディアを優先。各主張に出典URLと日付を付ける。
- 憶測・不確実な点は「※推測」と明示。

【出力フォーマット】
1. エグゼクティブサマリー（重要ポイント5〜7個）
2. 各トピックの詳細（事実＋出典URL＋日付）
3. 「あびこの個人サロンへの示唆」（うちの店にどう効くか）
4. 今月試すべき打ち手 上位5（優先度／工数／期待効果を添えて）
5. 出典一覧
```

## ■ テーマ別ブロック（その月のぶんを基本ブロックの下に足す）

### 固定① 競合サロン定点観測
```
【今回のテーマ：近隣の競合サロン定点観測】
大阪市住吉区あびこ〜昭和町・西田辺・帝塚山・長居・住之江エリアの美容室について調べてください。
- 新規オープン／閉店の動き
- 目立つキャンペーン・クーポン・価格帯（特に髪質改善・縮毛矯正・白髪系）
- Google/HPBの口コミ評判（点数・件数・褒められている点・不満点）
- 各店の強みメニュー・打ち出し方・SNS発信の傾向
- 上位表示されている店の共通点
```

### 固定② 翌月の季節・需要トレンド先読み
```
【今回のテーマ：翌月〜再来月の季節・需要トレンド先読み】
これから1〜2ヶ月で美容室の需要が伸びるメニュー・悩み・検索ワードを予測してください。
- 季節要因（例：梅雨→うねり/髪質改善・縮毛矯正、夏→紫外線/白髪ぼかし 等）
- 伸びる検索ワード・SNSで話題の施術
- 打ち出すべきキャンペーン・ブログ/投稿ネタの提案
```

### ローテ③ 美容業界の集客・経営トレンド
```
【今回のテーマ：美容業界の集客・経営トレンド】
- ホットペッパービューティー(HPB)の最新の仕様変更・掲載プラン・料金/掲載ロジックの変化
- Googleビジネスプロフィール(MEO)の美容室集客での最新動向・仕様変更
- 美容室の集客チャネルの変化（HPB依存からの脱却・Google・公式LINE・Instagram・リピート施策）
- 客単価・値上げ動向、物価・人件費・材料費の経営インパクト
- 美容師の採用市況（採用難・給与相場・業務委託化の動き）
```

### ローテ④ 同業の発信リサーチ（Threads/note）
```
【今回のテーマ：同業の発信リサーチ】
「AI×美容室経営」「1人・個人サロン経営」「美容師の発信」で伸びているThreads・noteを調べてください。
- 伸びているアカウント/記事の切り口・型・投稿頻度・時間帯
- 有料note・メンバーシップの価格帯と売れ筋テーマ
- マネできる勝ちパターンと、避けるべき地雷
```

### ローテ⑤ Threadsアルゴリズム/トレンド更新
```
【今回のテーマ：Threadsの最新アルゴリズム・トレンド】
- 直近のアルゴリズム/仕様変更（表示・おすすめ・リーチの決まり方）
- 伸びる投稿の型・文字数・時間帯・リプライ運用の最新セオリー
- 2026年に効くフォーマット、逆に効かなくなったもの
```

### ローテ⑥ AI×美容室・小規模事業の新事例/ツール
```
【今回のテーマ：AI×美容室・小規模事業の新事例とツール】
- 美容室/小規模店舗でのAI活用の新事例（集客・予約・接客・オペレーション・経理）
- 使えそうな新しいAIツール・サービス（料金と使いどころ）
- 実店舗で成果が出た/失敗した具体例（→ レーンBの実録ネタにも）
```
