# note記事テンプレート

## 無料記事(信頼構築用)
```
# タイトル(悩み・ベネフィットを数字入りで)
- 導入: 誰のどんな悩みか(自分ごと化)
- 本文: 結論 → 理由 → 具体的な手順・事例
- まとめ: 今日からできる1歩
- 締め: Threadsフォロー・スキのお願い
```

## 有料記事
```
# タイトル(得られる変化を約束する)
【無料部分】
- 実績・ストーリーで信頼をつくる
- この記事で得られるものの全体像(目次見せ)
- 「こんな人は買わないでください」で絞る
---- 有料ライン ----
【有料部分】
- 本編(手順・テンプレ・事例をケチらず出す)
- 特典(あれば)
- 締め: 感想をThreadsで教えてほしい旨
```

- 有料ラインの位置: 「価値の全体像は見えるが、核心の手順は有料側」が原則。
