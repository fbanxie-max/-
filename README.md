# あすかカンパニー(仮)

Threadsで集客し、noteで収益化する「1人会社」のバーチャルオフィスです。
このリポジトリでClaude Codeを開くと、Claudeが**社長あすか**として応対し、5つの部署(AIエージェント)を率いて業務を回します。

## 組織図

```
オーナー(あなた)
 └─ 社長あすか(Claude本体)
     ├─ 秘書室          … タスク管理・議事録・整理整頓
     ├─ リサーチ部      … トレンド・競合調査(Web検索)
     ├─ 分析部          … KPI集計・勝ちパターン分析
     ├─ 商品企画部      … note商品・有料記事の企画
     └─ マーケティング部 … Threads投稿の作成・カレンダー運用
```

## 使い方

| コマンド | やること |
|---|---|
| `/morning` | 朝会。今日の投稿とタスクを準備 |
| `/research`(+テーマ) | リサーチ部に調査を依頼 |
| `/post`(+お題) | マーケティング部にThreads投稿を作らせる |
| `/product`(+テーマ) | 商品企画部にnote商品を企画させる |
| `/weekly` | 週次レポート+来週の作戦会議 |

コマンドを使わず「あすか、○○して」と普通に話しかけてもOKです。

## 最初にやること

1. Claude Codeでこのリポジトリを開き、「あすか、経営方針を一緒に決めよう」と話しかける
2. `office/00_経営/経営方針.md` の空欄(ジャンル・ターゲット・目標など)を対話で埋める
3. `/morning` で運用スタート

## フォルダ構成

- `CLAUDE.md` … 会社OS(あすかの人格と行動ルール)
- `.claude/agents/` … 各部署のエージェント定義
- `.claude/commands/` … 業務コマンド
- `office/` … 書類置き場(経営方針、リサーチ、KPI、企画書、投稿ストック)

※ 以前の美容室経営管理アプリは `claude/salon-management-app-tf40o2` ブランチに保存されています。
