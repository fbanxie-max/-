# かんたん家計簿(Kakeibo)

夫婦・家族で使う、続けやすさ最優先の家計簿アプリです。`kakeibo.html` をスマホのブラウザで開き、「ホーム画面に追加」するとアプリのように全画面で使えます。

## 機能一覧

| 分類 | 機能 |
|---|---|
| 入力 | **サッと入力** — 大きなテンキーで金額→カテゴリを1タップで保存(最短2アクション)。保存時に残予算を即表示 |
| | **ワンタップ登録(定番)** — 「コンビニ ¥500」などよくある支出をボタン化して1タップで記録 |
| | **電卓機能** — 「300+450+120」とその場で足し算して合計を登録 |
| | **支払者タグ** — 夫/妻/共同など誰が払ったかを記録(名前は自由に変更・追加可) |
| | **特別費** — 旅行・家電などの大きな臨時支出を月予算と別枠で管理。「今月使いすぎ!?」の誤判定を防ぐ |
| ホーム | 今月の収入・支出・収支、全体予算の消化バーと「1日あたり使える額」、カテゴリ別予算バー(80%で黄・超過で赤)、**先月比**、**今週のふりかえり**、貯金目標の進捗、最近の記録 |
| 履歴 | 月送りのリスト表示(カテゴリ/支払者/テキスト絞り込み)と**カレンダー表示**。タップで編集・削除 |
| レポート | カテゴリ別支出の円グラフ、12ヶ月の収支推移グラフ、支払者別集計、**年間レポート**(カテゴリ×月クロス集計・特別費一覧) |
| 貯金 | **貯金目標トラッカー** — 目標額と積立記録、進捗バー。今月の黒字を積立の目安として表示 |
| 自動化 | **固定費・定期収入の自動記帳** — 家賃・サブスク・給与などを毎月決まった日に自動計上(🔁マーク付き) |
| 設定 | カテゴリと月予算の管理、メンバー管理、**月の開始日**(給料日締め対応)、ライト/ダークテーマ、JSONバックアップの書き出し/読み込み、サンプルデータ投入 |

## 使い方

1. `kakeibo.html` をブラウザ(スマホ推奨)で開く
2. 「入力」タブで金額を打ってカテゴリをタップするだけで記録できます
3. 「設定」でカテゴリごとの月予算や固定費を登録すると、ホームが充実します
4. 動作を試したいときは「設定 → サンプルデータを投入」

## データについて

- データは**この端末・このブラウザの中だけ**に保存されます(外部送信なし)
- 夫婦で使う場合は、共有の端末1台で入力する運用がおすすめです
- 機種変更やデータ消去に備え、「設定 → バックアップを書き出す」で定期的にJSONを保存してください

# サロン経営管理(Salon Manager)

美容室の経営に必要な日々のタスクを1つにまとめた管理アプリです。
**`index.html` をブラウザで開くだけ**で動作します。サーバーやインストールは不要で、データはお使いの端末(ブラウザのlocalStorage)に自動保存されます。

## 機能一覧

| 分類 | 機能 |
|---|---|
| ホーム | **ダッシュボード** — 今日/今月の売上・支出・利益、月別収支グラフ、今日の予約・シフト、在庫アラート |
| 日々の業務 | **予約管理** — 日別の予約台帳。来店処理(会計)をすると売上と顧客カルテに自動反映 |
| | **収支管理** — 収入・支出の記録、カテゴリ別集計、月次サマリー、CSV出力 |
| | **領収書管理** — 写真付きで保管(自動縮小)、経費カテゴリ、支出への同時計上、CSV出力 |
| スタッフ | **シフト管理** — 週間シフト表、休憩控除、週合計時間 |
| | **給料管理** — シフトの勤務時間×時給(または月給)+担当売上×歩合率で自動計算。手当・控除の調整、人件費としての支出計上、CSV出力 |
| | **スタッフ登録** — 給与形態(時給/月給)・歩合率の設定 |
| 物品 | **発注管理** — 未発注→発注済→納品済のステータス管理。納品時に在庫へ自動加算、支出への計上 |
| | **在庫管理** — 薬剤・店販商品・備品。最低在庫を下回るとアラート |
| 顧客 | **顧客カルテ** — 来店履歴、施術メモ(カラーレシピ等)、髪質・好みのメモ、検索 |
| その他 | **設定・バックアップ** — 店名設定、JSONバックアップの書き出し/読み込み、サンプルデータ投入 |

## 使い方

1. `index.html` をブラウザ(スマホでも可)で開く
2. まず「スタッフ登録」でスタッフを登録すると、シフト・給料・担当売上が使えるようになります
3. 動作を試したいときは「設定・バックアップ」→「サンプルデータを投入」

## データについて

- データは**この端末・このブラウザの中だけ**に保存されます(外部送信なし)
- 機種変更やブラウザのデータ削除に備え、「設定・バックアップ」から定期的にJSONバックアップを保存してください
- 収支・領収書・給与はCSV(Excel対応)で書き出せます
