# サロン経営管理(Salon Manager)

美容室の経営に必要な日々のタスクを1つにまとめた管理アプリです。
**`index.html` をブラウザで開くだけ**で動作します。サーバーやインストールは不要で、データはお使いの端末(ブラウザのIndexedDB)に自動保存されます(数百MB規模。施術写真・領収書写真も多数保存可能)。

## 機能一覧

| 分類 | 機能 |

| | **月次レポート** — ダッシュボードの「月次レポート」ボタンまたはレポート一覧から。月を選んで実績サマリー(前月比・**前年同月比**)・グラフ・内訳を1画面に表示。印刷/PDF保存・メール送信・本文コピーに対応 |

| | **レジ締め** — 日別の支払方法別売上(現金/カード/QR/その他)と現金照合。金種表(1万円札〜1円玉の枚数)を入力すると釣銭準備金・実査額の合計を自動計算し、過不足をリアルタイム表示。**日別メモ**(天気・出来事など)は日報一覧・CSVにも表示 |
| | **領収書管理** — 写真付きで保管(自動縮小)、経費カテゴリ、支出への同時計上、CSV出力 |
| スタッフ | **シフト管理** — 週間シフト表(開始・終了だけの簡単入力)、週合計時間。**休憩中も時給を支払う方針のため開始〜終了の全時間で給料を計算**(休憩の入力なし)。週40時間超は⚠表示(割増賃金の目安) |
| | **給料管理** — シフトの勤務時間×時給(または月給)+担当売上×歩合率で自動計算。**時給スタッフの1日8時間超・22時以降(深夜)は25%増しの割増賃金を自動計算**(月給者の残業は警告表示)。**源泉所得税の徴収漏れ(月8.8万円以上で0円)・最低賃金割れを自動警告**。手当・控除は**項目別**(通勤手当/源泉所得税/雇用保険料/その他)に記録でき、給与明細・CSVに労働日数・時間外/深夜時間・控除内訳を記載(賃金台帳に近づけた様式)。**基本給・歩合・手当・控除の金額はタップでその場で変更可能**(表示中の月分から新しい金額で計算し、それより前の月は自動で旧額のまま=昇給履歴を自動記録。「いつから昇給」の設定は不要)。**締日・支払日に対応**(既定は20日締め・当月25日払い。設定で1〜28日/末日・当月/翌月に変更可)し、「7月分=6/21〜7/20」のように締日ベースの期間で集計。手当・控除の調整、人件費としての支出計上(1人ずつ/**「全員分を支出に計上」で一括**。計上日は支払日。**事業主本人の分は経費ではなく「事業主貸(利益からの受け取り)」として記録**され、支出・利益に影響しない)、**利益カード(売上−経費−給料=利益。計上済み人件費の二重引きは自動排除)**、**給与明細の印刷/PDF(対象期間・支払日つき)**、**スタッフ生産性(時間あたり売上・労働分配率)**、CSV出力 |
| | **スタッフ実績(月次まとめ)** — 月末や気が向いたときに、スタッフごとの技術売上・店販売上・客数・新規数・指名数を**月単位でまとめて入力**(毎日の入力は不要。月の途中でも上書きOK)。入力すると**客単価・新規率・指名率・店販比率・売上ランキング(棒グラフ)・直近6ヶ月の推移**を自動分析し、**給料管理の歩合・スタッフ別売上グラフ・生産性カードにもこの数字が反映**される(未入力のスタッフは担当付きの売上記録から自動集計)。店の売上には二重計上されない |
| | **スタッフ登録** — 給与形態(時給/月給)・歩合率・**区分(従業員/家族従業員(青色事業専従者)/事業主本人。事業主の給料は納税予想で自動足し戻し、家族は届出の注意を表示)**・**入社月/退社月**・**給与改定履歴(昇給時に適用開始月を指定すると過去の月は旧額のまま計算)**の設定。退社したスタッフは削除せず退社月を入れると、在籍していた月の給料管理・明細には残り続け(給与履歴の保持)、退社後の月には表示されません |

## 使い方

1. **正式URL: https://fbanxie-max.github.io/-/** をブラウザ(スマホでも可)で開く(GitHub Pagesで公開。このブランチへのpushで自動更新)。スマホは「ホーム画面に追加」(Safari: 共有→ホーム画面に追加 / Chrome: メニュー→ホーム画面に追加)でアプリのように使えます。`index.html` を直接開いても同じように動作します。
   **注意: claude.aiのArtifactプレビューなどサンドボックス表示ではデータが保存されません**(その場合は画面上部に警告バナーが出ます)。日々の利用は必ず上の正式URLで。
2. まず「スタッフ登録」でスタッフを登録すると、シフト・給料・担当売上が使えるようになります
3. 「設定・バックアップ」で**月間売上目標**を入れると、ダッシュボードに達成メーターと着地見込みが表示されます
4. 動作を試したいときは「設定・バックアップ」→「サンプルデータを投入」

## 月次レポートのPDF保存・メール送信

1. ダッシュボード右上の「月次レポート」を開き、‹ › で対象月を選ぶ
2. **PDFにする**: 「印刷 / PDF保存」→ ブラウザの印刷画面で送信先を「PDFに保存」にして保存(ダークテーマ利用中でも印刷は自動でライト配色になります)
3. **メールで送る**: 「メールで送る」でメールアプリが開き、5行のサマリーが本文に入ります。内訳まで送りたいときは「本文をコピー」で全文をコピーして貼り付けてください

## 将来の課題

- 予約リマインダーの自動送信・オンライン予約受付は、サーバーを持たない構成(単一HTML)のため対応していません。電話番号のタップ発信で代替してください
- 複数端末でのデータ自動同期は非対応です。「設定・バックアップ」のJSON書き出し/読み込みで受け渡してください

## データについて

- データは**この端末・このブラウザの中だけ**に保存されます(外部送信なし)
- 保存先はIndexedDB(容量は端末により数百MB〜数GB)。旧バージョンのlocalStorageデータは初回起動時に自動移行されます。IndexedDBが使えない環境ではlocalStorage(約5MB)の簡易保存モードで動作し、設定画面にその旨が表示されます
- 現在の使用量と残り容量の目安は「設定・バックアップ」に表示されます
- 機種変更やブラウザのデータ削除に備え、「設定・バックアップ」から定期的にJSONバックアップを保存してください。古いバージョンのバックアップや一部項目が欠けたファイルも、読み込み時に自動補正されます
- 収支・領収書・給与はCSV(Excel対応)で書き出せます
