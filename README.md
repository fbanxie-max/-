# あすかカンパニー(仮)

Threadsで集客し、noteで収益化する「1人会社」のバーチャルオフィスです。
このリポジトリでClaude Codeを開くと、Claudeが**AI CEO**として応対し、オーナー(あすかさん)の指示のもと5つの部署(AIエージェント)を率いて業務を回します。

## 組織図

```
オーナー: あすかさん(人間・あなた)
 └─ AI CEO(Claude本体)… オーナーと直接対話する唯一の窓口
     ├─ 秘書室          … タスク管理・議事録・整理整頓
     ├─ リサーチ部      … トレンド・競合調査(Web検索)
     ├─ 分析部          … KPI集計・勝ちパターン分析
     ├─ 商品企画部      … note商品・有料記事の企画
     └─ マーケティング部 … Threads投稿の作成・カレンダー運用
```

## 使い方

| コマンド | やること |
|---|---|
| `/morning` | 朝会。今日の投稿とタスクを準備 |
| `/research`(+テーマ) | リサーチ部に調査を依頼 |
| `/post`(+お題) | マーケティング部にThreads投稿を作らせる |
| `/product`(+テーマ) | 商品企画部にnote商品を企画させる |
| `/weekly` | 週次レポート+来週の作戦会議 |

コマンドを使わず「○○して」と普通に話しかけてもOKです。

## 毎日の運用

`office/10_秘書室/運用ルーティン.md` 参照。基本は「朝 `/morning` で投稿受け取り → 夜18〜21時に投稿+30分リプライ返し → 数字をAI CEOに報告」の1日1時間ルーティンです。

## フォルダ構成

- `CLAUDE.md` … 会社OS(AI CEOの役割と行動ルール)
- `.claude/agents/` … 各部署のエージェント定義
- `.claude/commands/` … 業務コマンド
- `office/00_CEO室/` … 経営方針・意思決定ログ
- `office/10_秘書室/` … タスクボード・運用ルーティン
- `office/20_リサーチ部/` … 調査レポート
- `office/30_分析部/` … KPI記録・分析レポート
- `office/40_商品企画部/` … 商品企画書
- `office/50_マーケティング部/` … 投稿ストック・カレンダー・プロフィール案
- `office/90_テンプレート/` … 各種テンプレート

※ 以前の美容室経営管理アプリは `claude/salon-management-app-tf40o2` ブランチに保存されています。
