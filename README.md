# あすかカンパニー(仮)

Threadsで集客し、noteで収益化する「1人会社」のバーチャルオフィスです。
このリポジトリでClaude Codeを開くと、Claudeが**AI COO(最高執行責任者)**として応対し、CEO(あすかさん)の指示のもと実務を回します。

## 組織図(CEO=あすかさん / COO=AI の最小体制)

```
CEO 兼 オーナー: あすかさん(人間・あなた)… 最終意思決定者・ビジョンの主。最終決裁と投稿・返信の実行者
 └─ AI COO(Claude本体)… CEOの意向を実務に落として会社を回す執行トップ。CEOと直接対話する窓口
     ├─ [直轄業務] 秘書・分析・投稿作成・商品企画・部署運営はCOOが回す
     └─ [契約スタッフ] リサーチ担当 … Web検索調査が必要な時だけ呼ぶ
```

意思決定・決裁はCEO、実務の執行はCOO。人員(サブエージェント)の増員は、業務量が増えたタイミングでCOOがCEO(あすかさん)に提案し、決裁を得てから行います。

## 使い方

| コマンド | やること |
|---|---|
| `/morning` | 朝会。今日の投稿とタスクを準備 |
| `/research`(+テーマ) | リサーチ部に調査を依頼 |
| `/post`(+お題) | マーケティング部にThreads投稿を作らせる |
| `/product`(+テーマ) | 商品企画部にnote商品を企画させる |
| `/weekly` | 週次レポート+来週の作戦会議 |

コマンドを使わず「○○して」と普通に話しかけてもOKです。

## 毎日の運用

`office/10_秘書室/運用ルーティン.md` 参照。基本は「朝 `/morning` で投稿受け取り → 夜18〜21時に投稿+30分リプライ返し → 数字をAI COOに報告」の1日1時間ルーティンです。

## フォルダ構成

- `CLAUDE.md` … 会社OS(AI COOの役割と行動ルール)
- `.claude/agents/` … 各部署のエージェント定義
- `.claude/commands/` … 業務コマンド
- `office/00_CEO室/` … 経営方針・意思決定ログ
- `office/10_秘書室/` … タスクボード・運用ルーティン
- `office/20_リサーチ部/` … 調査レポート
- `office/30_分析部/` … KPI記録・分析レポート
- `office/40_商品企画部/` … 商品企画書
- `office/50_マーケティング部/` … 投稿ストック・カレンダー・プロフィール案
- `office/90_テンプレート/` … 各種テンプレート
