AI COOとして朝会を開いてください。手順:

1. `office/00_CEO室/経営方針.md`、`office/10_秘書室/タスクボード.md`、`office/50_マーケティング部/コンテンツカレンダー.md`、`office/30_分析部/KPI記録.csv`、`office/30_分析部/失敗リスト.md` を読んで現状と過去の失敗を把握する。

2. **経営数字を取得する(経営分析室・Drive連携)**。Googleドライブの収支表 **「2026年ブレイヴシザー収支管理メインvol2」**(fileId: `1RfY8NNzJKHqNuq4rs3sTy-E06R2KJ4OF`)を読む。fileIdで開けない場合は `title contains '収支管理メイン'` で検索して最新の同名ファイルを使う。読めたら**今月のシート**から次を拾う:
   - 昨日の日次売上(前営業日。休業日=¥0はスキップして直近の営業日を「昨日」とする)
   - 今月の 売上累計 / 経費 / 人件費 / 利益(実績) / 予測最終利益 / 損益分岐点まで残り
   - 材料費率・人件費率・経費比率、前年同月比(あれば)
   - ⚠️ **Driveが未接続で読めないときは、数字を絶対に創作せず**「⚠️ Drive未接続のため財務数字はスキップ(コネクタをONにして再実行を)」と報告し、以降の手順は続ける。

3. 昨日の数字(フォロワー数・閲覧・いいねなど)をオーナーに聞き、報告があれば `KPI記録.csv` に追記し、投稿ストックの実績メモも更新する。

4. 今日投稿予定のThreads投稿が `office/50_マーケティング部/投稿ストック.md` に用意済みか確認。無ければCEOが自分で作成する(テンプレと勝ちパターン準拠)。

5. オーナーに報告(簡潔に、この順):
   - **①経営ヘッドライン**(手順2の数字。1〜2行。例「昨日の売上¥47,400／今月売上累計¥1,241,290・利益+¥190,081・分岐点まであと¥548,710」)。読めなかった場合は⚠️行のみ。
   - **②今日の投稿**(**コードブロックで提示** — コピーボタンでワンクリックコピーできるように。引用形式は使わない)
   - **③今日のタスク**
   - **④CEOからの一言提案**

6. タスクボードを今日の状態に更新し、変更をコミット・プッシュする。
